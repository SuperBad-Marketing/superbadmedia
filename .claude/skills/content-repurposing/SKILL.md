# Content Repurposing

How to maximise value from every piece of content by fragmenting it across formats, platforms, and time.

## The Fragmentation Principle

One piece of content should never be one post. Every asset contains multiple fragments that can live independently across different formats. The effort is in the creation — the distribution should be nearly free.

## Repurposing Matrix

### From a Carousel Post (5-10 slides)
| Fragment | Format | Platform | Effort |
|---|---|---|---|
| Full carousel | Carousel post | Instagram feed | Original |
| Single best slide | Single image post | Instagram feed | Extract |
| Slide 1 (hook) | Story with "See full post →" CTA | Instagram Stories | Extract |
| Quote pull from one slide | Quote graphic | Instagram feed, later | Extract |
| Key point list from slides | Text post | LinkedIn (future) | Rewrite |
| Slide-by-slide narration | Reel / video walkthrough | Instagram Reels | Record |
| Behind-the-scenes of creation | Story sequence | Instagram Stories | Capture |

## Timing Strategy

### Staggered Release
Don't post all fragments at once. Stagger them:

```
Day 0: Original carousel post
Day 1: Story with "See yesterday's post" + behind-the-scenes
Day 3: Quote pull from best-performing slide (standalone post)
Day 7: If the original performed well, reel walkthrough of the content
Day 14+: Evergreen repurpose — the core insight reframed
```

### Seasonal Recycling
Great content can be reposted 3-6 months later with:
- Updated design (new template, current brand styling)
- Refreshed caption (new angle on the same insight)
- Added context ("6 months ago I posted this. Here's what happened since.")

The audience has turned over. What felt repetitive to you is new to 80% of current followers.

### Evergreen vs Timely
- **Evergreen content** (tips, frameworks, observations): repurpose freely across months
- **Timely content** (trends, news, seasonal): one-week window, then archive
- **Portfolio content** (work samples): repurpose annually or when the work gets updated/new results

## Content Studio Integration

When the AI strategy engine recommends repurposing:

### Auto-Suggestions
After a post performs well (top 20% engagement), automatically suggest:
1. "Pull slide 3 as a standalone quote post" → pre-fills Content Studio with the copy and a quote template
2. "This carousel's hook slide works as a standalone" → pre-fills with slide 1 copy
3. "Create a follow-up post expanding on [best-performing point]" → pre-fills brief

### Pre-Filled Briefs
The "Generate this" button from strategy recommendations should:
1. Set the content type based on the recommendation
2. Pre-fill the brief with context from the original post
3. Suggest a template that matches the fragment type
4. Include a note about the source post for continuity

### Fragment Tracking
Track which posts are fragments of which originals:
- `parent_post_id` on Content Studio posts
- Prevents recommending fragments of fragments
- Enables aggregate performance analysis: "this original generated 4 fragments with combined reach of X"

## Quality Guardrails

### When NOT to Repurpose
- The original performed poorly (bottom 30%). Don't amplify bad content.
- The content was timely and the moment has passed.
- The fragment loses meaning without the original context.
- You've already repurposed the same original twice. Move on.

### Repurpose vs Repost
- **Repurpose:** transform the content into a different format or angle. This adds value.
- **Repost:** share the exact same thing again. This is lazy and the algorithm notices.
- Always repurpose, never repost. Even small changes (new caption, different crop, updated stat) make it fresh.

### Brand Consistency
Every fragment should:
- Use the current brand templates (not the original's design, if it's outdated)
- Get a fresh caption (not copy-pasted from the original)
- Stand alone — if someone sees only this fragment and never the original, it should still make sense
