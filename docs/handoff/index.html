The complete technical reference for SuperBad Lite. Everything your team needs to understand the platform, its systems, and how they connect.

Stack: Next.js 16 + SQLite + Drizzle Date: 28 April 2026 Audience: Dev Team

SuperBad Lite is an operations platform for a marketing agency. It handles lead generation, sales pipeline, client onboarding, invoicing, content creation, and a client-facing portal — all run by a solo founder with AI doing the heavy lifting. Every LLM call routes through a central model registry. Every state change is logged. Every feature is gated by a kill switch.

The documents below cover each system independently. Start with whichever system you’re building into. The architecture diagram shows how they connect.
