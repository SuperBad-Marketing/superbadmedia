# Surprise & Delight — Seed Riddles

Content source for S&D spec §Riddle loop. Initial batch of 3 riddles for the `/say/[answer]` resolver. Each includes the social post text, the correct answer, common wrong answers with dry micro-responses, the catch-all wrong response, and reward content for both public and logged-in visitors.

All wrong-answer responses and rewards are generated by `generateInVoice()` and drift-checked. These are the calibration seeds.

---

## Riddle 1 — Grandmother

### Social post
"the number of times my grandmother said 'I told you so' at dinner last year."

### Answer
`fourteen`

### Common wrong answers (pre-generated responses)

| Wrong answer | Response |
|---|---|
| zero | "you don't know my grandmother." |
| one | "one? she's more committed than that." |
| seven | "close, but she doubled down after Christmas." |
| twelve | "you're thinking monthly. she's thinking per argument." |
| fifteen | "off by one. which is how most arguments start." |
| once | "technically a number. technically wrong." |
| daily | "that's not a number. also, yes." |

### Catch-all wrong response
"no. but grandmother would appreciate the effort."

### Public reward
Hidden page with warm charcoal background, centred text in Playfair Display italic:
"fourteen. she counted. we counted. nobody won."

### Logged-in reward
Same page + a tiny fork icon (Playfair Display, 12px, Retro Pink) appears permanently in the user's profile sidebar footer. Hover text: "fourteen".

## Riddle 2 — Camera

### Social post
"the thing every marketing agency promises but only one of them brings to the first meeting."

### Answer
`camera` (also accepts: `a camera`, `the camera`)

### Common wrong answers

| Wrong answer | Response |
|---|---|
| ideas | "everyone brings ideas. we bring equipment." |
| results | "that's a good answer for a pitch deck. not for this." |
| strategy | "strategy comes after you've seen what you're working with." |
| portfolio | "portfolios are PDFs. we bring something heavier." |
| coffee | "that too, actually. but no." |
| honesty | "flattering. but no." |
| data | "data is what we bring to the second meeting." |

### Catch-all wrong response
"not quite. think less abstract, more optical."

### Public reward
Hidden page: a full-bleed still photograph (SuperBad portfolio shot, warm tones), no text except a small line at the bottom in DM Sans italic: "we bring the camera. everything else follows."

### Logged-in reward
Same page + a tiny camera icon (12px, Retro Pink) in the profile sidebar footer. Hover text: "the camera".

## Riddle 3 — Melbourne

### Social post
"the city where it rains four times before lunch and nobody mentions it."

### Answer
`melbourne` (also accepts: `melb`, `melbs`)

### Common wrong answers

| Wrong answer | Response |
|---|---|
| london | "london talks about the weather. that's the difference." |
| seattle | "seattle made rain a personality trait. we just own a jacket." |
| sydney | "sydney would complain." |
| auckland | "close, geographically. wrong country." |
| manchester | "they'd write a song about it." |
| brisbane | "brisbane panics when it rains once." |

### Catch-all wrong response
"no. think southern hemisphere, bad weather, no complaints."

### Public reward
Hidden page: warm charcoal background, the word "Melbourne." centred in Black Han Sans, with a very subtle animated rain effect (same as the Melbourne Rain egg, 20% volume, respects user prefs). Below in DM Sans: "four seasons before lunch. wouldn't have it any other way."

### Logged-in reward
Same page + a tiny umbrella icon (12px, Retro Pink) in the profile sidebar footer. Hover text: "melbourne".
